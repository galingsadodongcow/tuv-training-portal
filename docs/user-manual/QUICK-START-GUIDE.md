# Quick-Start Guide — Academy Portal

One-page procedures for the highest-frequency tasks. Full detail in **USER-MANUAL.md**.

## First 5 minutes (any role)
1. **Sign in** with your work email + password (accounts come from your Super Admin).
2. You land on your **home** — most roles: **My Work**; Management: **Overview**; Auditor: **Search/Audit**.
3. Press **⌘K / Ctrl-K** anytime → type to jump to a page, or type a name to find a record.
4. Check the **notification bell** (top right) for anything waiting on you.
5. On **My Work**, work top-down: tasks, approvals, orders/sessions needing attention, exceptions.

## Operations — daily
| I want to… | Do this |
|---|---|
| See what needs staffing | **Calendar → List view**, filter by Status = Tentative |
| Assign a trainer/venue | Click the session → in the drawer, pick Trainer + Venue (1 click each) |
| Confirm a session | Open session → **Go/No-Go → Confirm Go** (below minimum → *Confirm Go anyway*) |
| Add a new course | **Training catalogue → + New course** (title, category→subcategory, learning type + fee) |
| Schedule a run | **Calendar → Book**, or **New session** (course + learning type + dates) |
| Enrol people | Session → **Participants → Add** or **Import CSV** |
| Mark attendance / certify | Session → Participants → **Mark attendance**, then **Issue certificate** / **Issue all** |
| Fulfil orders | **CRM → Orders → Needs fulfilment** → Advance / Assign (select rows for bulk) |
| Cancel a session | Session → **More → Cancel with dispositions** (needs Business-Owner approval) |

## Sales — daily
| I want to… | Do this |
|---|---|
| Log a lead | **CRM → Pipeline → + New inquiry** (Company required). *Search ⌘K first to avoid duplicates.* |
| Qualify it | Pipeline table → **Edit** (value, probability, close); advance the stage |
| Quote | **CRM → Quotes → New quote** → add lines (price auto-fills; apply discount hint) |
| Book an order | **CRM → + New order** → Customer, **Order number**, lines (course, session, seats, fee) |
| Hand to Operations | Order → **Endorsement → Endorse to Operations** (then tell Ops if urgent) |

### Three things that trip everyone up
1. **Course ≠ Session.** Course = template (no dates). Session = one scheduled run. You sell seats in sessions.
2. **Endorsement isn't a notification.** Endorsing an order moves it to Operations' queue but doesn't ping them — say so if it's urgent.
3. **Almost nothing deletes.** Participants are removed (soft), payments voided, orders cancelled. Look for those verbs, not "Delete".
